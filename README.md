# مدیریت کلینیک مسیحا — نسخه مستقل ۱.۰

وب‌اپ مستقل مدیریت کلینیک فیزیوتراپی با PHP 8.3 و MariaDB؛ هیچ وابستگی اجرایی به OpenEMR ندارد. رابط فارسی، راست‌چین و مبتنی بر فونت Vazirmatn (وزیرمتن) است.

## امکانات پیاده‌سازی‌شده

- داشبورد بر اساس داده واقعی، برنامه روز و نمودار جلسات هفت روز اخیر.
- ثبت و ویرایش پرونده بیمار، جستجو و صفحه‌بندی، ایمیل اختیاری، شماره همراه یکتا.
- تقویم شمسی و ورودی شمسی؛ تاریخ و ساعت دیتابیس میلادی، منطقه زمانی تهران.
- دوره درمان، ارزیابی، اهداف، احتیاط‌ها، تمرین خانگی و شمارش جلسات.
- نوبت با کنترل هم‌زمانی بیمار، درمانگر، اتاق و دستگاه؛ سقف جلسات دوره.
- نتیجه جلسه، درد قبل/بعد، دامنه حرکت، لغو و عدم مراجعه.
- دریافت و بازگشت وجه، مانده دوره، ثبت‌کننده تراکنش، جلوگیری از بازپرداخت بیش از دریافتی.
- مدیر، پذیرش، درمانگر و مالی با محدودیت سمت سرور؛ ثبت رویدادهای مهم.
- تنظیم نام، تماس، نشانی، آپلود لوگوی PNG/JPG و روشن/خاموش کردن راهنمای فیلدها.
- مدیریت همکاران، اتاق‌ها، تجهیزات و تعرفه‌های مرجع.
- پورتال بیمار: ورود با موبایل و کد یک‌بارمصرف، رزرو زمان‌های منتشرشده، لغو، بارگذاری مدارک و مشاهده روند درمان.
- مدارک خصوصی خارج از webroot، محدودیت حجم و نوع، بررسی دسترسی هنگام دانلود.
- تنظیمات پیامک کاوه‌نگار؛ ارسال واقعی به کلید و الگوی تأییدشده نیاز دارد و پیش‌فرض خاموش است.

## نصب روی سرور تازه

Ubuntu 24.04 و دامنه متصل به IP سرور لازم است. پورت‌های ۸۰ و ۴۴۳ باید قابل دسترسی باشند.

```bash
sudo bash setup.sh clinic.example.com
```

فایل نصب، بسته‌های PHP، Nginx، MariaDB و SSL را نصب و تنظیم می‌کند. برای دامنه‌ای که قبلاً کانفیگ Nginx دارد، ابتدا کانفیگ قدیمی را پشتیبان و از `sites-enabled` خارج کنید تا دو میزبان هم‌نام فعال نباشند.

- آدرس ورود کارکنان: `/login`
- آدرس بیمار: `/patient/login`
- سلامت سرویس: `/health`
- مشخصات اولیه مدیر: `/etc/masiha-clinic/install.json`، فقط قابل خواندن برای root.
- پیکربندی برنامه: `/etc/masiha-clinic/config.php`.
- دیتابیس: `masiha_clinic`؛ حساب دیتابیس فقط به همین پایگاه دسترسی دارد.
- مدارک و تنظیمات پیامک: `/var/lib/masiha-clinic`، خارج از مسیر عمومی.

نصب مجدد، رمز مدیر و داده‌های موجود را بازنویسی نمی‌کند. وجود دیتابیس بدون فایل پیکربندی باعث توقف نصب می‌شود. در نصب روی سرور قبلی، اگر فایل مشخصات مدیر نسخه قبلی وجود داشته باشد همان نام کاربری و رمز اولیه برای اولین مدیر استفاده می‌شود.

## شروع کار مدیر

۱. در «تنظیمات کلینیک» نام، لوگو و اطلاعات تماس را وارد کنید.
۲. در «همکاران و دسترسی‌ها» درمانگران و پذیرش را بسازید.
۳. در «خدمات و منابع» اتاق‌ها و دستگاه‌ها را تعریف کنید.
۴. بیمار و سپس دوره درمان را ثبت کنید؛ بعد نوبت بدهید.
۵. برای رزرو آنلاین از «تقویم ← زمان‌های آزاد برای رزرو بیمار» زمان منتشر کنید.
۶. برای ورود بیمار، شماره همراه اختصاصی، اجازه ورود در پرونده و تنظیمات پیامک لازم‌اند.

## آزمون‌ها

روی سرور تست، با root:

```bash
python3 tests/integration.py https://clinic.example.com
php tests/otp.php
```

آزمون‌ها فقط رکوردهای مصنوعی خود را می‌سازند و پاک می‌کنند؛ نام و رمز مدیر در خروجی چاپ نمی‌شود. آزمون OTP از فرستنده تزریق‌شده استفاده می‌کند و پیامک واقعی نمی‌فرستد. آزمون رزرو بیمار از نشست مصنوعی محدود به همان بیمار تست استفاده می‌کند؛ هیچ مسیر ورود آزمایشی در برنامه عمومی وجود ندارد.

## محدودیت‌های نسخه ۱.۰

این نسخه پایه مستقل مدیریت فیزیوتراپی است، نه معادل تمام قابلیت‌های سامانه قبلی یا بقراط. بیمه و نسخه الکترونیک، ویزیت صوتی/تصویری، درگاه پرداخت، سهم درمانگر و حسابداری دوبل، نوبت تکرارشونده و گزارش‌ساز پیشرفته هنوز پیاده‌سازی نشده‌اند. تعرفه خدمات در این نسخه مرجع است؛ مبلغ کل هر دوره جداگانه تعیین می‌شود.

قبل از استفاده درمانی واقعی، آزمون پذیرش با کارکنان، ارزیابی امنیت مستقل، سیاست نگهداری اطلاعات، بکاپ خارج از سرور و آزمون بازیابی لازم است. هیچ داده نمونه‌ای به‌جای آمار واقعی نمایش داده نمی‌شود.

## ساختار

- `app/`: منطق مستقل، کنترل دسترسی، فرم‌ها، پورتال و تبدیل تاریخ.
- `public/`: تنها ریشه قابل دسترسی وب؛ کنترل‌گر و دارایی‌های ظاهری.
- `deploy/`: طرح دیتابیس، نصب اولیه، Nginx، پشتیبان و بازیابی.
- `tests/`: آزمون گردش اصلی و کنترل‌های OTP.
- `docs/`: راهنمای انتقال و سابقه استقرار.

فونت Vazirmatn با مجوز OFL توزیع می‌شود؛ متن آن در پوشه فونت‌ها موجود است.

## نسخه ۱.۱ — پنل مدیریت
دسترسی‌های جزئی، داشبورد مدیریت و درمانگر، خدمات و دسته‌ها و پکیج‌ها، سهم همکار، لیبل، فرم‌های عمومی و ویزیت، نوبت‌دهی با جستجوی زنده، گزارش‌های مالی و تنظیم فونت و رنگ اضافه شده‌اند.
راهنمای کامل، تعریف دقیق گزارش‌ها و محدودیت‌های این مرحله: [docs/ADMIN-1.1.md](docs/ADMIN-1.1.md).
ارتقای نسخه مستقل قبلی: `sudo bash deploy/upgrade.sh`؛ نصب تازه با `setup.sh`.

## نسخه ۱.۲ — انتقال بقراط
تنظیمات و آرشیو انتقال در `/imports` اضافه شده است. موتور اختیاری با `sudo bash deploy/install-importer.sh` نصب می‌شود. حدود پوشش و مراحل آزمون اولیه در [docs/IMPORT.md](docs/IMPORT.md) آمده است.


## نصب کامل روی سرور ایران

برای نصب تازه روی Ubuntu 24.04، فایل setup علاوه بر وب‌اپ، MariaDB، PHP/Nginx، Python/Playwright، Chromium/Xvfb، سرویس و تایمر importer و ابزار بکاپ را نصب می‌کند.

اگر DNS دامنه هنوز به سرور جدید منتقل نشده است:

    sudo bash setup.sh clinic.example.com --skip-ssl

پس از انتقال DNS:

    sudo certbot --nginx -d clinic.example.com --redirect

برای بررسی مسیر شبکه سرور جدید تا سرویس‌های بقراط:

    bash deploy/check-boghrat-network.sh 5

لاگ زنده importer:

    journalctl -fu masiha-importer.service -o cat
