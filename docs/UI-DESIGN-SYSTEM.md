# طراحی سراسری رابط کاربری کلینیک مسیحا

## ساختار

ظاهر جدید از فایل `public/assets/modern-ui.css` بارگذاری می‌شود. این فایل بعد از `/theme.css` قرار دارد و همهٔ صفحات مدیریتی، پذیرش، داشبورد، پرونده‌ها، فرم‌ها، گزارش‌ها، امور مالی، انبار، صفحه ورود و پورتال بیمار را پوشش می‌دهد. هیچ تغییری در API، مجوزها، دیتابیس یا روند عملیات به‌خاطر این لایهٔ CSS لازم نیست.

## اصول بصری

- زبان فارسی و چینش RTL، فونت Vazirmatn با قلم معمولی و ضخیم.
- پس‌زمینه روشن، کارت‌های سفید، کنارهٔ سرمه‌ای و فیروزه‌ای تیره برای عملکرد اصلی.
- دکمهٔ اصلی `#0b827c` با نوشتهٔ سفید و نسبت کنتراست تقریبی 4.67:1.
- فضای کافی و دسته‌بندی دیداری برای فرم‌ها و جدول‌ها؛ آیکن‌های حداقل 44 پیکسل در موبایل.
- رنگ وضعیت‌ها وابسته به معنای وضعیت است، نه صرفاً تزئین.
- لیبل و هشتگ دو موجودیت مجزا هستند؛ CSS فقط شکل نمایش آن‌ها را تعیین می‌کند.

| مورد | رنگ |
|---|---|
| نوار کناری | `#142d4c` |
| رنگ اصلی | `#0b827c` |
| هاور اصلی | `#086a68` |
| پس‌زمینه | `#f4f7fc` |
| متن اصلی | `#172b4c` |
| متن مکمل | `#687b96` |
| مرزها | `#dfe8f2` |
| کارت‌ها | `#ffffff` |

رنگ‌های تنظیمات «ظاهر» در جدول `settings` باقی می‌مانند و قابلیت ویرایش از صفحهٔ مربوطه حفظ شده است. مقادیر پیش‌فرض در `app/admin-api.php`، `app/display.php` و `app/admin-views.php` نیز با طراحی جدید هماهنگ شده‌اند.

## حفظ قابلیت‌ها

لایهٔ طراحی نباید ویژگی‌های HTML `hidden`، مجوزها، اعداد و اطلاعات بیمار، ثبت مراجعه، وضعیت گردش کار، تاریخ‌های شمسی و فرم‌های مالی را تغییر دهد. در توسعه‌های بعدی، CSS صفحهٔ جدید در فایل مربوط به خودش قرار گیرد و اجزای عمومی از `modern-ui.css` استفاده کنند.
